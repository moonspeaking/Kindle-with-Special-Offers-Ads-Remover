Если вы приобрели электронную книгу Kindle по акции "Специальные предложения", этот скрипт удалит рекламу, которая отображается при блокировке устройства (вам не нужно платить за это 10 долларов на Amazon :D). 
Для этого не требуется взлом или рут, и гарантия не будет аннулирована, так как скрипт просто удаляет внутренний путь, где хранится реклама.
